How to deploy the config

  1. Make your visibility changes using the toggles on this page
  2. Click "Download dashboard_config.json"
  3. Go to your GitHub repository
  4. Navigate to the data/ folder
  5. Upload / replace dashboard_config.json with the downloaded file
  6. Commit the change
  7. The dashboard reads this config on every page load — changes go live within the 5-minute auto-refresh cycle
Tip: You can keep this dashboard_admin.html file in the root of your GitHub Pages site so you can access it anytime at yourdomain/dashboard_admin.html
